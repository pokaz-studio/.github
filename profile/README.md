# Pokaz Studio

3D product configurators for makers, from the first idea to the order.

Shoppers try every material, colour, size and part on the product in 3D, with a live price,
in the browser on any device. Orders go out by email, through their own checkout, or into
Shopify, WooCommerce or a headless cart.

**A team, from the first call to launch and after.** Pokaz Studio is a developer, a 3D artist
and a UX designer, with every project led by the founder, Przemysław Rakowski. We plan, model and
build each configurator, then look after it: full configurator care from A to Z.

**Ready for AI assistants.** Every configurator publishes an `llms.txt` with its catalog and
prices, so a chat assistant can quote it and link to the exact configuration. Browser agents
can drive every feature through WebMCP.
